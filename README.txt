# Adaptive Puzzle Generator

A Java-based puzzle generation framework developed as a Software Architecture course project.

## Overview

Adaptive Puzzle Generator is designed to create and manage different puzzle types while demonstrating object-oriented design principles and software architecture patterns.

The project incorporates multiple software design patterns to improve extensibility, maintainability, and scalability.

## Design Patterns Implemented

- Factory Method
  - Creates puzzle objects through a centralized factory interface.

- Composite
  - Represents puzzle structures using hierarchical components.

- Decorator
  - Adds optional functionality such as hints, scoring, and time limits.

- State
  - Adjusts puzzle difficulty based on user performance.

- Scheduler
  - Manages puzzle generation requests and prioritization.
